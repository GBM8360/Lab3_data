# GBM8360E — Lab 3 data

Data for Exercise 3 of Laboratory 3 (A2026), *Physical Principles of Advanced MRI*, Polytechnique Montréal.

Download **`lab3-ex3-collaborator.zip`** from this repository's [Releases](https://github.com/GBM8360/Lab3_data/releases). It contains:

| File | Contents |
|---|---|
| `collab_dwi.nii.gz` | Diffusion-weighted images of a phantom (64 × 64 × 1 × 19) |
| `collab_mask.nii.gz` | Mask of the phantom |
| `collab_dti.qmrlab.mat` | qMRLab `dti` protocol and options |
| `collab_dwi.bval`, `collab_dwi.bvec` | The same protocol, in FSL format |

See the lab handout for instructions.
